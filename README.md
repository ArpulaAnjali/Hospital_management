# Hospital Management System - CarePlus

A beginner-friendly Hospital Management System website developed using only HTML, CSS, and Vanilla JavaScript. The project is designed as a college mini-project for 2nd-year B.Tech students.

## Live Demo
The application is deployed and hosted live on Vercel:
👉 **[CarePlus Hospital Live Link](https://hospital-management-mu-rosy.vercel.app)**

## Features
1. **Home Page**: Complete welcome section, navigation bar, services list, about hospital info, and dark mode toggle.
2. **Patient Registration**: Form with full JavaScript client-side validations, temporary persistence in Local Storage, and success alerts.
3. **Doctor Information**: Card listings for 6 specialists including contact numbers and scheduling times.
4. **Appointment Booking**: Form with date checking (cannot book in the past) and dropdown selectors, saved dynamically in Local Storage.
5. **Patient Records Database**: Dynamic table showing registered patients, supporting active search/filters by patient name and deletion capabilities.
6. **Admin Dashboard**: Real-time summary statistics (total counts of patients, doctors, appointments) and action shortcuts.
7. **Contact Page**: Structured query form, address, map details, phone, and support emails.
8. **Dark Mode Theme**: Persisted color layout switcher driven by JavaScript.

## Technology Stack
- **Structure**: Semantic HTML5
- **Style**: Custom Vanilla CSS3
- **Logic**: Vanilla JavaScript (ES6+)
- **Icons**: Font Awesome v6

## How to Run Locally
1. Clone this repository.
2. Open `index.html` directly in any web browser.
